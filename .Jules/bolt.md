## 2025-01-01 - [Optimize wc by replacing compound boolean with static lookup array]
**Learning:** Hot C processing loops containing compound boolean checks for whitespace run slower due to branching overhead. Using a 256-element static boolean lookup array `is_space_lookup` instead drastically eliminates branches and speeds up performance on ASCII byte streams. Also, applying an ASCII-based byte-by-byte scanning loop in a multibyte streaming path is incorrect; properly utilizing `mbrtowc` and `iswspace` within the multibyte loop correctly evaluates multibyte streams as per POSIX expectations, without breaking wide-character alignment.
**Action:** Always replace compound boolean checks with static lookup arrays in hot byte loops. Use multibyte functions appropriately when dealing with locale-dependent byte processing, avoiding strictly ASCII optimizations in wide character paths.
